# Introduction

This folder contains examples for text to speech with Dart API.

| File | Description|
|------|------------|
|[./bin/piper-lexicon.dart](./bin/piper-lexicon.dart)| Use a Piper tts model for text to speech. See [./run-piper-lexicon.sh](./run-piper-lexicon.sh)|
|[./bin/coqui.dart](./bin/coqui.dart)| Use a Coqui tts model for text to speech. See [./run-coqui.sh](./run-coqui.sh)|
|[./bin/vits-zh-lexicon.dart](./bin/vits-zh-lexicon.dart)| Use a Chinese VITS tts model for text to speech. See [./run-vits-zh-lexicon.sh](./run-vits-zh-lexicon.sh)|
|[./bin/zipvoice-zh-en-lexicon.dart](./bin/zipvoice-zh-en-lexicon.dart)| Use a ZipVoice Chinese/English zero-shot TTS model. See [./run-zipvoice-zh-en-lexicon.sh](./run-zipvoice-zh-en-lexicon.sh)|
